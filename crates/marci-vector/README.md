# Модуль гибридной индексации и ранжирования объектов на основе многомерных семантических и пространственных признаков с хранением индекса в базе данных

Данный модуль предоставляет высокопроизводительный алгоритм построения и поиска по векторным индексам, основанный на рекурсивной кластеризации данных и поддержке композитных метрик расстояния.

В отличие от классических решений (HNSW, IVF, Annoy), индекс может полностью храниться в key–value базе данных и эффективно выполнять поиск без загрузки всего дерева в оперативную память, а также поддерживает комбинированные многомерные расстояния, включающие разные типы признаков (например, геопозицию + семантические embeddings).

Модуль является частью исследовательской работы и разрабатывается как отдельная патентоспособная технология.

## 🔍 Основные особенности

### 1. Рекурсивное построение дерева кластеров (K-Means Tree)

Алгоритм разбивает данные на уровни через K-Means, формируя дерево кластеров произвольной глубины:

* каждый узел содержит центроид кластера;
* листья содержат реальные точки;
* глубина и ширина адаптивны и определяются распределением данных;
* структура хранится в базе данных через бинарные ключи.

Это позволяет:

* эффективно индексировать миллионы объектов;
* выполнять поиск без загрузки всего индекса в память;
* организовать компактное представление дерева в KV-хранилищах.

### 2. Поддержка составных (композитных) метрик

Модуль позволяет задавать гибридную метрику из нескольких компонентов, например:

* евклидово расстояние на поддиапазоне (например, координаты),
* косинусная близость на embeddings,
* пользовательские расстояния,
* взвешивание каждого компонента.

Пример:

```rust
CustomDistance::Complex(vec![
    (Box::new(CustomDistance::Euclidean), 0, 2, 0.3),       // геолокация
    (Box::new(CustomDistance::Cosine), 2, 2562, 1.0),      // смысловые эмбеддинги
])
```

Это даёт возможность:

* объединить географическую близость и смысловое сходство;
* строить единый гибридный индекс для сложных многомерных объектов;
* получать более точное ранжирование результатов.

### 3. Хранение индекса в базе данных

Индекс сохраняется не в оперативной памяти, как HNSW/Annoy, а в KV-структуре:

* каждый кластер и лист имеют бинарный ключ вида:

  * `CLUSTER`: `<len><path...><0x00>`
  * `LEAF`:    `<len><path...><0x01><id>`
* чтение осуществляется через префиксный перебор;
* глубина дерева не ограничена RAM.

Преимущества:

* работает в серверных и встроенных системах;
* поддерживает персистентность и инкрементальное обновление;
* индекс можно передавать на клиент (офлайн-поиск).

### 4. Быстрый поиск ближайших соседей

Поиск осуществляется через:

* обход дерева кластеров начиная с корня;
* раннее отсечение плохо подходящих кластеров;
* max-heap для топ-k результатов;
* SIMD-ускорение операций (через `std::simd`).

Особенности:

* поддержка padding для любых размерностей;
* threshold-фильтрация для снижения шума;
* адаптивное ветвление на основе расстояния до центроидов.


### 5. Возможность выполнения поиска на фронтенде

Дерево кластеров можно сериализовать и передать:

* в браузер (WebAssembly),
* в мобильное приложение,
* в оффлайн-режим.

Это открывает новые сценарии:

* приватный поиск без передачи векторов на сервер,
* офлайн-каталоги достопримечательностей,
* локальные рекомендации,
* локальная фильтрация данных на клиенте.

## 📦 Использование

Поскольку в данной реализации испольуется механизм portable_simd (который дает преимущественное ускорение), нужно использовать nightly версию rust

```
rustup default nightly
```

### Построение индекса

```rust
let points: Vec<(Vec<u8>, Vec<f32>)> = ...;
storage.create_cluster(&mut ctx, &points, CustomDistance::Euclidean);
```

### Поиск ближайших

Для того, чтобы найти ближайшие, нужно указать итератор по данным. Алгоритм ищет нужные элементы по префиксу, поэтому ваше Key-Value хранилище должно поддерживать поиск через range

Реализацию итератора на стандартной BTreeMap можно посмотреть в файле `src/lib.rs`, раздел `[tests]`.

Пример поиска:

```rust
let results = storage.find_nearest_points(
    &ctx,
    &target_vector,
    10,
    CustomDistance::Cosine,
    0.05,
);
```

## 🧬 Особенность этого модуля

Этот модуль объединяет:

* метод кластеризации (KMeans)
* структуру дерева (hierarchical cluster tree)
* сложные гибридные расстояния
* полноценную персистентность в базе данных
* возможность работы на фронтенде
